# assets/

- `founder.jpg` is a generated placeholder monogram for **Prakash Chand Srivastava (PCS Sir)**.
- To use the real photo, **replace `assets/founder.jpg`** with a square-ish portrait (JPG, roughly 512×512 or larger). Keep the file name.
- The game tries `founder.jpg`, then `founder.png`, then falls back to the monogram drawn in code.
- Players can always upload their own photo in-game; it is stored only in their browser.
